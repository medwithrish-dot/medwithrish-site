Any depicted people must be male; use readable opaque backgrounds.

HOW TO USE
Copy one prompt at a time into your image generator. Save the result using the filename shown.

Use these rules for every image:
- Landscape, 1600 x 1000 pixels.
- Clean, modern medical-education worksheet on a white background.
- British English, large readable text, high contrast and no logos.
- Use exactly the labels, numbers and wording supplied.
- Do not include an answer, explanation, coloured hint or highlighted correct choice.
- All people, organisations and data are fictional.

IMPORTANT: Image generators often misspell text or change numbers. Check every finished image against this file before using it.
